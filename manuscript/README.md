# Manuscript compilation

Included files:

- `Yixuan_Wang_AISC_manuscript.tex`: manuscript source.
- `Yixuan_Wang_AISC_manuscript.pdf`: rendered manuscript supplied by the author.
- `aisc_main_results_figure.png`: aggregate-results figure referenced by the source.

The source uses the publisher's `BVP_AISC` document class. The class file and publisher logo are not redistributed because their independent redistribution terms were not established during preparation of this public export. Obtain the current official AI and Security Convergence template directly from the publisher, place `BVP_AISC.cls` and its required assets beside the source as directed by that template, and compile with a LaTeX engine compatible with the official instructions.

The included PDF is the frozen rendered manuscript artifact; compilation of the `.tex` file requires the separately obtained official template.
